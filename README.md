# ⚽ SportGear – Premium Sports & Fitness Equipment Frontend

SportGear is a fully responsive, feature-rich modern web frontend for an e-commerce platform specializing in athletic wear, footwear, and gym equipment. Built with **Tailwind CSS**, **Font Awesome**, and vanilla **JavaScript**, it provides a complete simulated online shopping experience directly in the browser.

## ✨ Key Features & Functionality

*   **1. Comprehensive Sports Marketplace:**
    *   Browse premium sports items across key categories (Footwear, Apparel, Gym Equipment, and Team Sports & Accessories).
    *   Dynamic real-time search and category filtering system.
    *   Interactive price range sliders (up to ₹25,000) and sorting options (Low to High, High to Low, Featured).
*   **2. Interactive Product Details & Variant Selection:**
    *   Detailed view for each item showcasing high-resolution product imagery, descriptions, and variant choices (Standard vs. Pro Series).
*   **3. Dynamic Shopping Cart & Simulated Checkout:**
    *   Full cart management with instant quantity updates, real-time subtotal calculations, and free delivery threshold indicators.
    *   Multi-step checkout workflow supporting shipping address input and multiple payment methods (UPI / PhonePe / Google Pay / Paytm, Cards, and Cash on Delivery).
    *   Toast notification feedback system for seamless user experience.
*   **4. Wishlist & User Account Management:**
    *   Save favorite items to a personalized wishlist with quick toggle options.
    *   Simulated user profile dashboard displaying user information and saved products.
*   **5. Multi-View SPA Navigation:**
    *   Single Page Application architecture supporting dynamic switching between Home, Products, Product Details, Cart, Checkout, User Account, About Us, and Contact pages without full page reloads.

## 🛠️ Technology Stack

*   **HTML5 & CSS3** (Semantic layout and custom styling)

*   **JavaScript (ES6+)** (Dynamic DOM rendering, filtering, state management, and view routing)
*   **Font Awesome (v6.4.0)** (Icons)
*   **Google Fonts** (Modern typography)
